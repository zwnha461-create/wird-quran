# ورد القرآن 📖

تطبيق ويب عربي (RTL) للوِرد اليومي من القرآن الكريم — مصحف المدينة، ٦٠٤ صفحات.

## فكرة التطبيق

- زرّ واحد «ورد جديد» يسحب صفحات متتالية عشوائية (٤ افتراضيًا، قابلة للتعديل) من الصفحات **غير المقروءة فقط** — لا تتكرر أي صفحة حتى تختم المصحف كاملًا.
- الورد المسحوب يبقى «معلّقًا» ولا تُحتسب صفحاته إلا بعد الضغط على «أتممت القراءة».
- متابعة: حلقة تقدم من ٦٠٤، سلسلة الأيام المتتالية، الموعد المتوقع للختمة، تقويم الأيام المتمّة، سجل الأوراد، واحتفال عند إتمام الختمة مع عدّاد ختمات ودورة جديدة.
- إجراءات الورد: متابعة ورد معلّق، تراجع عن آخر إتمام، «صفحات أخرى» (استبدال بصفحات مختلفة)، حذف الورد (وحذف ورد مكتمل يعيد صفحاته لغير المقروءة).
- قارئ صفحة-بصفحة بخط أميري: نقر الكلمة لسماع نطقها، ونقر رقم الآية لسماع تلاوتها كاملة بصوت الشيخ **علي جابر**، مع تشغيل الورد كاملًا بالتتابع.
- شريط أدوات أعلى القارئ: وضع «جوال / آيباد» (توسيع الصفحة)، تكبير الخط، والسمات (فاتح / ورقي / داكن) — كلها محفوظة.
- مفضلة للآيات مع ملاحظات تدبّر.

## التشغيل محليًا

```bash
npm install
npm run dev      # خادم التطوير
npm run build    # بناء الإنتاج في مجلد dist
```

يتطلب Node.js ١٨ أو أحدث. لا توجد أي مفاتيح سرية أو إعدادات إضافية.

## الاستيراد إلى Bolt.new عبر GitHub

1. ارفع هذا المجلد إلى مستودع GitHub جديد (أو ادفع الملفات إلى مستودع موجود).
2. في Bolt.new اختر **Import from GitHub** واختر المستودع.
3. سيتعرف Bolt على مشروع Vite تلقائيًا — لا حاجة لأي أوامر إضافية، ثم انشر المشروع للحصول على رابط قابل للمشاركة.

> ملاحظة: لا ترفع مجلد `node_modules` — ملف `.gitignore` يستبعده أصلًا.

## البيانات والمصادر

- **كل حالة التطبيق** (الصفحات المقروءة، الأوراد، المفضلة، الإعدادات) تُحفظ في `localStorage` بالمتصفح تحت المفتاح `wird-quran-v1` — بدون خادم وبدون حسابات، والبيانات خاصة بكل جهاز/متصفح.
- **نص الصفحات** يُجلب وقت التشغيل من واجهة Quran.com العامة (v4):
  `GET https://api.quran.com/api/v4/verses/by_page/{page}?words=true&per_page=50&word_fields=text_uthmani,location,audio_url&fields=text_uthmani,chapter_id,verse_key`
- **صوت الكلمة الواحدة**: `https://audio.qurancdn.com/` + حقل `audio_url` من الاستجابة (مثل `wbw/001_001_001.mp3`) — مقاطع تعليمية من Quran.com، ليست بصوت علي الجابر.
- **تلاوة الآية كاملة**: بصوت علي جابر من EveryAyah:
  `https://everyayah.com/data/Ali_Jaber_64kbps/{SSS}{AAA}.mp3` (أرقام السورة والآية بثلاث خانات).
- قاعدة الأمان: لا تصبح الكلمات قابلة للنقر إلا بعد تحقق آلي داخل التطبيق من أن قائمة كلمات الصفحة تطابق نصّها تمامًا (ترتيبًا وعددًا)؛ عند عدم التطابق يُعرض النص عاديًا وتبقى تلاوة الآيات متاحة.
- لا يتم تضمين نص القرآن داخل الكود — كل شيء يُجلب من المصادر أعلاه عند الحاجة ويُخزّن مؤقتًا في الذاكرة فقط.
